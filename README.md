# 📊 Interactive Sales Dashboard (Power BI)

## 📌 Project Overview
This project presents an interactive business dashboard built using Power BI. The dashboard provides insights into sales performance, regional trends, and product category analysis to support data-driven decision-making.

---

## 🎯 Objective
Design an interactive dashboard for business stakeholders to monitor performance and identify growth opportunities.

---

## 🛠 Tools Used
- Power BI
- Data Visualization
- Business Intelligence

---

## 📂 Dataset
Sales / Financial dataset from Kaggle

The dataset includes information related to:
- Sales transactions
- Regions
- Product categories
- Order dates
- Customer segments

---

## 📊 Dashboard Features

### ✅ KPI Summary
- Total Sales
- Total Orders / Quantity
- Overall performance snapshot

### 📈 Sales Trend Analysis
- Time-series analysis of sales
- Identifies seasonal trends and growth patterns

### 🌍 Regional Performance
- Sales comparison across regions
- Identifies high-performing markets

### 🛍 Category Performance
- Sales distribution by category
- Highlights top-performing product segments

### 🏆 Top Products / Contributors
- Identifies key revenue contributors

### 🎛 Interactive Filters
- Date
- Region
- Category
- Segment

These filters allow users to explore data dynamically.

---

## 🧠 Key Insights

- Certain regions contribute significantly to total sales.
- Sales performance varies across product categories.
- Seasonal trends influence purchasing behavior.
- A small group of products contributes a large share of revenue.

---

## 🎨 Dashboard Design Highlights
- Clean and professional layout
- Consistent corporate color theme
- Interactive slicers for easy exploration
- Clear visual hierarchy for decision-making

---

## ▶️ How to Use

1. Download the `.pbix` file from the repository.
2. Open using **Power BI Desktop**.
3. Use filters to explore insights.
